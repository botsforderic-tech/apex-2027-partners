# APEX 2027 Partner Overview

Static partner proposal page for APEX. Hosted on GitHub Pages.

- `index.html`: the whole page (styles and script inline)
- `media/`: video, photos and icons

Passcode gate is client side only. Change the passcode by replacing `PASS_HASH` in index.html with the SHA-256 of the new passcode in uppercase. Visit logging: set `LOG_URL` in index.html to a Google Apps Script web app URL.
